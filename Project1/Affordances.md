Affordances "perceivable action possibilities"

Actual Affordance "The objective, true action possibilities"
    - Draw on screen - Via Nib
    - View information about the pen on the dot matrix display
Percieved Affordances "Affordances that the user thinks the object has" "The user may think"
    - Touch a/the button to perform an action
    - User can Bluetooth pair and charge the pen
    - Draw with pressure (angular?) sensitivity on screen
    - Record audio (apparently online ppl know of pens that do this)
Hidden Affordance "Hidden affordances that are not seen at first and require an action to be seen"
    - "RGB Color Signifier" (Appears when pen is connected with a color / charging)
    - "Modular Back" (Ability to change the back functionality by unscrewing / replacing)

Signifiers "Tell us what do do"
    - May have a twist indicator if it has a modular back
