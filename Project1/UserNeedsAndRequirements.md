# Requirements

## From Interviews 
These needs are not ordered. They come from the numbered question answers.
1. On-Pen Gesture controls
2. Pressure functionality
3. Quality weight (Good heft)
2. Programmable controls
4. Magnetic
5. Charges on Back of Ipad
6. Can Pair with Drawing Tablet
3. 100% Accurating lines drawing Feature
4. Pen can quickly change drawing colors
4. works with different software.
5. works as smart pen
6. Has near-standard form factor
7. Notes and Drawing users can enjoy the pen.
8. Eraser functionality on back. 
9. Easy To use
10. Undo / Redo Easily accessable
11. Can Fit differnt nib types
12. Uses EMR battery so never-needs-charge w/ tablet.
